# 第 8 章 候選：規則／演練／原文細節

來源：page_0031～page_0033

## (a) 規則候選

### 規則 1：金鑰只進機密管理，不進明文

- **規則一句話**：任何模型或服務金鑰只能放在環境變數或機密管理，不寫進檔案、設定檔、對話或指令列輸出。
- **Why**：第 8 章「誰帶鑰匙」小節的注意框指出，外洩的金鑰既是資安風險也是成本風險，撿到的人可以用你的帳單跑模型。
- **How to apply**：Claude 在設定代理、寫腳本或接 MCP 時，主動用 `os.environ`／`setx`／secret store 讀取；回報時只寫「來源＋長度＋是否成功」，看到明文金鑰出現在 git diff 時主動攔下並提醒。

### 規則 2：選代理＝同時決定錢、品質、資料流向

- **規則一句話**：建議用哪個代理或模型時，必須同時說明成本歸屬（扣誰的帳）、品質預期與資料會送到哪家供應商。
- **Why**：本章指出「我要用哪個 AI？」不是技術小事，而是一次同時牽涉金錢、品質與資料保護的決定；Paperclip 下指令、代理付帳。
- **How to apply**：Claude 在推薦 `claude -p`、直接 API、本機模型或第三方服務時，用一行列出「計費來源／資料去向／能力等級」，敏感資料預設建議不上雲的選項。

### 規則 3：「已宣布」不等於「已可用」

- **規則一句話**：引用新工具功能時，區分「官方已宣布」與「實際可用」，涉及敏感用途前先查第一手來源的現況。
- **Why**：本章對 Clipmart 市集與本機模型都強調 announced is not the same as available，年輕專案狀態變得很快。
- **How to apply**：Claude 在回答某功能是否存在時，若依據只是公告或部落格，明講「已宣布、未實測」，並主動查 GitHub／官方文件或做一次最小實測再下結論。

### 規則 4：接入代理即繼承其風險

- **規則一句話**：給代理越大權限，就要越嚴的審批與日誌；權限評估以「最壞被提示注入時會做什麼」為準。
- **Why**：本章注意框：工具無關代表 Paperclip 會繼承所選代理的弱點，例如被惡意輸入誘導做有害動作，治理只能限損不能歸零。
- **How to apply**：Claude 設定 `claude -p` 無頭代理時，主動用 `--tools` 限縮工具、不給對外寄信或刪檔權限，對外動作改成產草稿等人核准。

## (b) 演練候選

### 演練 1：用 claude -p 當「員工」，體會「適配器只負責溝通、不負責品質」

1. 準備一個簡單任務檔 `task.txt`：「列出 3 個 Node.js 20 的新功能，每項附官方文件網址」。
2. 用兩種設定各跑一次：`claude -p --model haiku "$(cat task.txt)" > out-haiku.md`、`claude -p --model sonnet "$(cat task.txt)" > out-sonnet.md`。
3. 自己逐項核對網址是否真實存在、內容是否正確。

- **預期結果**：同一個「指派語言」（同樣的 prompt）丟給不同員工，產出品質不同；體會本章「適配器是口譯員，不是老師」，品質取決於員工本身。

### 演練 2：金鑰外洩自我檢查

1. 在一個練習 repo 執行 `git grep -nE "sk-[A-Za-z0-9]{20,}|AIza[0-9A-Za-z_-]{30,}"`。
2. 檢查 `.gitignore` 是否排除 `.env`、`credentials.json`。
3. 用 `claude -p` 請它審查 repo 是否有明文金鑰並列出位置（不印值）。

- **預期結果**：得到一份「零明文金鑰」的確認，或找出需要搬進環境變數的位置。

### 演練 3：本機模型現況查證（只查不裝）

1. 到 Paperclip 官方 GitHub 搜尋 issues／discussions 中的 `Ollama`、`local model` 關鍵字。
2. 記下最新狀態（已合併、討論中、或無）與日期。

- **預期結果**：一份附日期的現況筆記，練習「已宣布 vs 已可用」的查證習慣（依使用者鐵律，不在本機跑模型）。

## (c) 書中具體細節（逐字）

- 原則名稱：`Bring Your Own Agent`
- 定位用語：`tool-agnostic`、`conductor layer`
- 連接機制：`adapters`（interpreters, not teachers）
- 適配器可接的代理：`Claude Code`、`Codex`、`Cursor`、`Gemini`、`Bash`（command line）、`HTTP`（通用網路服務適配器）、`OpenClaw`（HTTP 適配器的象徵範例）
- 擴充：`extensions (plugins)`
- 本機模型工具：`Ollama`
- 金鑰存放：`secret management`
- 市集名稱：`Clipmart`（已宣布、未確認可用）
- 交叉引用：第 4 章（公司可攜性／匯出）、第 7 章（治理）、法律章
- 指令、設定檔名、網址、版本號：無
